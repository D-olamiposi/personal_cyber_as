# Forensics and incident evidence

Acquire only approved evidence and document custody. Prefer a working copy; hash the original and acquired copy, preserve timestamps and record collection methods. Memory analysis requires compatible operating-system symbols and acquisition context. Disk artifacts, recovered files, packet captures and logs each have distinct limitations. Build timelines with normalized timezones while retaining originals. A recovered string is not proof that a command ran. Use Wireshark display filters to examine captured traffic; encrypted payloads may remain unavailable.
